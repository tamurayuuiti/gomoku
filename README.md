# Gomoku

React + TypeScript + Vite で構築した、ブラウザ上で遊べる五目並べアプリケーションです。対人戦と AI 戦に対応し、禁じ手ルールの有効・無効を切り替えながらプレイできます。AI の強さは 4 段階のレベルから選択でき、αβ枝刈り・反復深化・置換表・VCF・Quiescence Search などを組み合わせた探索エンジンが本格的な対局を実現します。ダークモードや設定の自動保存にも対応しています。

## 技術スタック

- React
- TypeScript
- Vite
- Tailwind CSS
- Web Worker（AI 思考処理）
- lucide-react
- ESLint
- Google Analytics 4 / Microsoft Clarity

## 主な機能

- 対人戦と AI 戦を切り替えてプレイできる
- AI 戦では先手・後手を選択できる
- AI の強さを 4 段階（初級・中級・上級・最強）から選択できる
- 禁じ手ルールの ON/OFF を切り替えられる
- 待った（Undo）機能で着手を取り消せる（AI 戦では自分の手番までまとめて戻す）
- 15×15 盤面上で勝敗・引き分けを判定する
- 対局終了時に結果ダイアログを表示し、その場での再対局または盤面の確認を選べる
- 対局中の設定変更は確認ダイアログを経由し、適用すると対局がリセットされる
- ゲーム設定（モード・先後・禁じ手・AIレベル）とテーマはブラウザに保存され、次回起動時に復元される
- ダークモードに対応し、テーマは「システム設定 / ライト / ダーク」の 3 状態で切り替えられる
- AI の思考を Web Worker 上で実行し、UI の応答性を維持する
- 最後の一手や禁じ手候補を盤面上で表示する
- 手番・手数・AI 思考中などの対局状態を盤面上部に表示する

## 動作フロー

1. ゲームモードと各種設定を選択する（設定は自動保存される）
2. 盤面に石を置く
3. 勝敗・禁じ手・引き分け条件を判定する
4. AI 戦では AI が次の一手を探索する
5. 盤面とステータスを更新する

## 技術・アルゴリズム・仕様

### 盤面・勝敗判定

- 盤面サイズは 15×15 です
- 横・縦・斜めの 4 方向で連続した石の数を確認します
- 黒はちょうど 5 連で勝利、白は 5 以上で勝利する判定を行います

### 禁じ手ルール

- 禁じ手ルールが有効な場合、黒の三三・四四・長連を判定します
- 五連完成時は禁じ手より勝利判定を優先します
- AI も禁じ手ルール設定を考慮して着手を決定します

### AI

- AI レベルは初級・中級・上級・最強の 4 段階で、レベルに応じて探索の深さ・思考時間・演出上の遅延を設定しています
- 候補手生成と盤面評価を組み合わせたミニマックス探索を採用しています
- αβ枝刈り・時間制限付き反復深化・PVS（Principal Variation Search）・LMR（Late Move Reduction）により探索効率を向上させています。ラインパターンを 3 進整数にエンコードしパターンテーブルで参照することで、評価・候補手生成を高速化しています
- TT Move・Killer・History・Countermove により有望な候補手を優先的に探索します
- 局面評価は、各方向のラインパターンに基づいて攻撃と防御の脅威をスコア化し、盤面全体の上位候補へ集約します。Top-K に漏れる中小脅威の累積価値を脅威密度ボーナスとして補助的に加算し、分散した脅威や厚みも評価に反映します
- Transposition Table・Zobrist Hashing・差分ラインキャッシュ・Static Eval Cache・候補集合の増分管理により、繰り返し局面と評価結果を再利用します。主要キャッシュは Typed Array による固定サイズハッシュテーブルで実装しています
- 連続四による即勝ち手順を短時間で証明する Root VCF（Victory by Continuous Four）と、葉ノードでの戦術的読み伸ばし（Quiescence Search）を備えています
- Threat Model に基づく forced move list の生成と、探索中の限定動的禁手判定により、禁手ルール下での戦術精度を向上させています

### 設定・テーマ

- ゲーム設定（対戦モード・先後・禁じ手ルール・AIレベル）とテーマはブラウザに保存され、次回起動時に復元します
- テーマは「システム / ライト / ダーク」の 3 状態を循環して切り替え、「システム」選択中は OS の配色設定に追従します
- 対局中の設定変更は確認ダイアログを経由し、適用すると現在の対局がリセットされることを明示します
